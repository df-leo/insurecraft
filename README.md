# InsureCraft ETL — week 3 starter (cp0)
Read `docs/brief.md`, `docs/user_stories.md` and `docs/definition_of_done.md`.
1. Copy `.env.example` to `.env` and fill it in (your trainer has the details). Put `policyholders.csv` in `data/`.
2. `pip install -r requirements.txt` then `pytest`.
3. Fill in the TODOs in `src/insurecraft_etl/` and `main.py`, writing a test for each rule. Run with `python main.py`.
