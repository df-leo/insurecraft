# InsureCraft user stories (week 3)

**Epic: a trusted claims dataset for the claims team.**

1. As a **claims analyst**, I want one row per valid claim, with invalid and incomplete claims removed, so that I can trust every figure I report.
2. As the **head of claims**, I want the total paid and the number of payments for each claim, so that I can see where money goes.
3. As a **regional claims manager**, I want each claim tagged with its region and local authority, so that I can compare performance across the country.
4. As the **data protection officer**, I want no names, dates of birth or raw policy ids in the analytical table, so that analysts cannot identify policyholders.
5. As a **data engineer**, I want the pipeline to run end to end with one command and be safe to rerun, so that refreshing the data never duplicates it.
6. As a **data engineer**, I want an untouched copy of every extract, so that any run can be audited or replayed.
